# FEEDBACK.dio
Desafio Criativo da Dio
🎯 Objetivo do Projeto

Utilizar Inteligência Artificial para analisar comentários de clientes do banco fictício DIOBANK, identificando:

Reclamações frequentes;
Elogios recorrentes;
Oportunidades de melhoria.
👥 Público-alvo
Desenvolvedores freelancers responsáveis por implementar melhorias;
Clientes do banco, que serão beneficiados pelas mudanças no aplicativo e nos canais de atendimento.
📦 Entrega Esperada

A IA deverá gerar:

Um resumo executivo;
Uma tabela com os principais temas encontrados;
Exemplos de comentários relacionados a cada tema;
Recomendações práticas para melhoria.
✅ Critérios de Sucesso

O resultado deve ser:

Claro;
Organizado;
Baseado exclusivamente nos comentários fornecidos;
Útil para definir prioridades de melhoria.
